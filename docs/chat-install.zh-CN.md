# 联机聊天安装与使用指南

[English](chat-install.md)

联机聊天模组为《杀戮尖塔 2》添加了游戏内消息、快捷回复和全队投票。本版本已在 Windows 上用游戏 **v0.113.1** 测试。

## 每位玩家都需要安装

1. 退出游戏，下载 **STS2_Coordination-0.2.0.zip**。所有队友都应安装相同版本的聊天模组。[联机聊天 0.2.0 下载](https://github.com/Britey/STS2MCP/releases/tag/chat-v0.2.0)
2. 在 Steam 库中右键单击《杀戮尖塔 2》，选择 **管理 → 浏览本地文件**。打开游戏目录下的 `mods` 文件夹。如果没有，手动创建。macOS 用户可以右键单击 `SlayTheSpire2.app`，选择 **显示包内容**，使用其中的 `Contents/MacOS/mods`。
3. 解压 ZIP，将整个 `STS2_Coordination` 文件夹复制到 `mods`。确认 DLL 和 JSON 文件都在同一层。

   ```text
   mods/
     STS2_Coordination/
       STS2_Coordination.dll
       STS2_Coordination.json
   ```

4. 启动游戏。如果出现允许加载模组的提示，请确认。在游戏的模组列表中查找 **STS2 Co-op Coordination**。开始或继续联机冒险，队友连接后，右上角会出现 **聊天** 按钮。

作为真人队友加入时，只需安装联机聊天模组。由 AI 操作的游戏还需要 MCP 桥接模组和 MCP 客户端。真人房主若想为全队设置 MCP 语言，也要安装桥接模组。[MCP 安装步骤](../mcp/README.zh-CN.md#安装与连接)

## 发消息、回复与投票

- 点击 **聊天**，选择一位队友，输入消息后点击 **发送** 或按 Enter。有多位队友时，可以选择 **所有队友**。
- 收到提问后，点击对应的快捷回复。如有 **输入回复** 按钮，也可以自行填写文字。若选了自己先出牌，操作完成后可以点击 **轮到你了**，让等待的队友继续。
- 全队投票中，每位收到提问的队友可以投一票。按票数决定时，得票最多的选项胜出。若平票，房主会收到只包含平票选项的第二轮投票。
- 对于「这回合有人能施加易伤吗？」这类问题，一票「是」就能确认。所有人都明确投「否」才能确认没有。如果无人投「是」，又有人未回复，则结果为未知。

## 由房主设置全队语言

在房主的游戏中打开 **设置 → 常规 → MCP 语言**，选择 **简体中文** 或 **English**。这会设置全队内置提问和回复按钮的语言，以及 MCP 返回的敌人、增益和减益名称。选择 **跟随游戏** 可恢复各自的语言偏好。手动输入的消息会原样发送。

找不到聊天按钮时，先检查模组列表中是否有 **STS2 Co-op Coordination**，以及是否有安装了同一版本的队友已加入。这是联机功能。更新后请重启游戏。如果以前手动装过旧版，把旧 DLL 和 JSON 移出 `mods`，只保留一份。
